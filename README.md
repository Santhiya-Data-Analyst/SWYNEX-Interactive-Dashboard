📊 Netflix Content Analysis - Interactive Dashboard

📁 About the Dataset
Netflix Movies and TV Shows dataset from Kaggle (by Shivam Bansal), cleaned in Task 1 and analyzed in Task 2.
- Cleaned file: Netflix_Cleaned.csv
- Total rows: 8,809

🛠️ Tools Used
Power BI Desktop

📈 Dashboard Overview
Built an interactive dashboard to visually communicate the key findings from the EDA, with KPI cards, charts, and filters for deeper exploration.

KPI Cards
- Total Titles: 8,809
- Total Movies: 6,131
- Total TV Shows: 2,676
- Top Country Count: 3,210
- Average Movie Duration: 99.6 minutes

Visuals Included
1. **Content Type Distribution (Pie Chart)** - Movies vs TV Shows split
2. **Top 10 Countries (Bar Chart)** - countries producing the most content
3. **Rating Distribution (Bar Chart)** - breakdown by content rating
4. **Content Growth Over Years (Line Chart)** - trend of titles added from 2008-2021

Interactive Filters (Slicers)
- Filter by Type (Movie / TV Show)
- Filter by Year Added

🔍 Key Insights Communicated
- Movies dominate the catalog (69.6%) over TV Shows (30.4%)
- United States, India, and United Kingdom are the top content-producing countries
- TV-MA is the most common content rating, indicating a mature-audience skew
- Content additions grew sharply between 2016 and 2020, peaking around 2019


📂 Files
- Netflix_Dashboard.pbix - Power BI dashboard file

## 📝 Note
A small number of rows (13 out of 8,809) had a missing date_added value, which shows as a negligible "0" point in the year-based trend chart. This does not affect the overall insights.
